会議を録音するだけで、**話しているそばから議事録・次に聞くべき質問・マインドマップが育っていく**ローカル実行ツール「LiveMTG」を作りました。無料のOSS（MIT）です。

```bash
npm install -g live-mtg@beta
live-mtg
```

# 何が新しいのか：APIキーが要らない

この手のAI議事録ツールはたくさんありますが、LiveMTGの設計上の賭けは1つだけです。

**「Claude Code（またはCodex）のサブスクを持っている人は、もうAIの利用権を持っている。それを会議に流用すればいい」**

LiveMTGはAPIキーを一切要求しません。AI処理はすべて、あなたのマシンにインストール済みの `claude` / `codex` CLIを使い捨てで呼び出すことで動きます。月額のSaaS料金も、従量課金の設定も、社内へのAPIキー配布もなし。**Claude Codeが動くマシンなら、追加コストゼロで会議コパイロットが動きます。**

音声も同じ思想で、文字起こしはローカルのWhisper（Apple SiliconならMLX、Intel Mac/Windowsはwhisper.cpp）。**会議の音声・文字起こし・議事データは1バイトもクラウドに出ません。** 顧客との商談や人事面談のような、外部SaaSに出しにくい会議でも使えます。

# できること

**ライブ（会議中）**
- リアルタイム議事録：要約・議題・決定事項・ToDo・未解決を15秒ごとに更新
- **次に聞く質問／次に話すこと**：会議の種類を判定し、商談なら「相手に聞く一問」、ブレストなら「次に話すと良い論点」を提案
- **解釈の確認**：AIが聞き取りに自信のない固有名詞（「なかたさん？たなかさん？」）をカードで確認してくる。✓/✗で答えると以降の解析に即反映
- **行き詰まりへの提案**：議論が煮詰まったのを検知すると、背景資料を踏まえた「対立する2案＋推し＋根拠」を出してくる
- 間違いに気づいたら「補足・訂正」に一言送れば、**過去の議事まで遡って**修正される

**会議後**
- 保存した全音声から高精度の清書を再生成（話者名の確認つき）
- **全部入り議事録PDF**：表紙〜決定事項〜未解決に加えて、放射マインドマップと「会話の関係」図（議論の流れをストーリーラインで図解）まで1ファイルに
- 「学びと次の一手」：自分の立場と目標に照らした振り返りレポート。会議の種類ごとのプレイブックに教訓を蓄積して、次回のAIガイドが賢くなる

# 仕組み（技術的な話）

構成は素朴です。Pythonのサーバ1本＋ブラウザUI＋外部CLIの組み合わせで、常駐のAIプロセスはありません。

```
ブラウザ録音(15秒チャンク) → whisper → transcript.txt
  → 即時解析(haiku・差分500字だけ) → data.json → UIが2秒ごとにポーリング
```

工夫している点をいくつか：

**1. モデルの3段構成** — ライブの差分解析は速度最優先でhaiku、準備チャットやWeb裏取りはsonnet、清書・スライド・振り返りは品質優先でopus。全部 `claude -p` の使い捨て実行なので、状態管理も接続維持もありません。

**2. 差分だけ渡す** — 毎回「新しく増えた発言500字＋現在の議事の小さな索引」しか渡さないので、3時間の会議でも1回あたりの解析コストが一定です。

**3. AIに頼らない部分を決めている** — 議事録PDFやマップのレイアウトは決定論のコード生成（AIを挟むと内容が落ちる・遅い・幻覚る）。逆に「解釈の確認」は、機械検出した未知語を小さなAI選別に通してから出す二段構え。**「どこにAIを使わないか」の設計が体感品質を決める**というのがこのプロジェクト最大の学びです。

**4. プロンプトの回帰テスト** — 「曖昧な人名→確認カードが出る」「明瞭な発話→出ない」「ブレスト→話す提案になる」のようなゴールデンケースを17件持っていて、プロンプトを変えるたびに実際にhaikuを叩いて検証します。「プロンプト変更で品質が黙って壊れる」を防ぐ仕組みです。

# 開発の裏話：AIと作っていて面白かった障害

このツール自体、ほぼ全部Claude Code（のさらに上位モデル）とペアで開発しているのですが、印象的だった障害を2つ。

**haikuが「長考」して全滅した話** — ライブ解析のAI呼び出し回数を減らそうと、複数の解析レーンを1つのプロンプトに統合したことがあります。結果、出力フィールドが11個・ルール大量のプロンプトになった途端、haikuの応答が3秒→40〜90秒に悪化。タイムアウトに連続29回引っかかって画面が完全に沈黙しました。**小さいモデルは「生成量」ではなく「判断の複雑さ」で遅くなる**。統合を撤回して細かいレーンに戻したら回復しました。

**Windowsの4連続の壁** — 日本語Windowsで動かしたら、①cp932で罫線文字が出力できず起動即死 → ②直したらMicrosoft Storeの「0バイトの偽python」を掴んで即終了 → ③直したらデータフォルダが2箇所に分裂していてモデルが見つからない → ④直したらwhisperのUTF-8出力をcp932で読もうとして解析スレッドが死亡。1つ直すと次が現れる4連コンボでした。現在は全部、製品側で自動回避します（UTF-8強制・pyランチャー優先・フォルダ自動統合）。

# 動作要件

- **Mac**（Apple Silicon / Intel両対応）または **Windows 11**
- Chrome（録音に使用。オンライン会議は「タブの音声共有」で相手の声も取れます）
- Node.js 20+
- **Claude Code または Codex のサブスクリプション**（各自のアカウントでログイン。これがAIエンジンになります）

初回の `live-mtg` でオンボーディングが始まり、ffmpeg・Whisper・モデルのダウンロードまで自動で案内します。
